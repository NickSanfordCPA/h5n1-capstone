# Post funnel: Meta and X side by side

This document counts what happens to every collected post on its way to the two analysis sets. One code path handles both platforms. Steps 1 to 8 are fixed rules (`h5n1/journal/funnel.py`); steps 9 to 16 use the reader labels (`h5n1/journal/label_funnel.py`). Each post is removed by the first step that applies to it, so the rows of the table sum to the total. Two sets come out: the **sentiment set** (Track A), every post a reader judged to be about avian influenza in one US state, and the **sightings** (Track B), posts about sick or dead animals at a named local place that are wildlife reports or first-hand accounts, kept as one per state-week per platform. No outcome data is used anywhere in the funnel.

Generated by `uv run python -m h5n1.journal.label_funnel report`; do not edit by hand.

## Step rules for the label steps

| # | Rule |
|---|---|
| 9 | The reader's `relevant` is no |
| 10 | The reader's `place_state` is `US`, `FOREIGN` or `NONE` |
| 11 | `illness` is no, or `local_place` is no |
| 12 | Content class `domestic_detection`: the outcome itself, or its dairy analogue |
| 13 | Content class `other` |
| 14 | The reader's `exclude` reason |
| 15 | Alaska, Hawaii or a territory |
| 16 | A later post in the same state and week (ending Sunday) as an earlier sighting, per platform |

Labels: every reader-set post was read twice by independent Sonnet readers. Where the reads differed on `relevant`, `content_class`, `place_state` or sighting status, an Opus adjudicator's row is used; otherwise read A's row (the reads agree on those fields).

The sentiment set keeps posts about Alaska, Hawaii and the territories; the state-week grid (48 states and DC) does not use them. A post whose reader state differs from the geocoder's state is placed in the reader's state.

Geocoder check on the sentiment set: the reader's state equals the geocoder's state for 99.4% of Meta posts and 99.6% of X posts. The geocoder is loose about *whether* a post is about one state: step 10 removes 13.7% of relevant Meta posts and 14.0% of relevant X posts.

## Labels after the X re-pull

The English X posts of 2022-06 to 2024-12 were first collected by an earlier scraper and were replaced on 2026-11-18 by a pull with the same collector and queries as the later period. Labels are keyed by post id. A post keeps its label when it returns with the same wording (the earlier export had lost commas and line breaks, so wording is compared on letters and digits only, without links); every other reader-set post was read twice after the re-pull.
